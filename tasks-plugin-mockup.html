Build Spec Notes
Sidebar Panel
→ Registered as a Leaf/View in Obsidian — persists like a sidebar pane
→ Group toggle: by note file or by heading within file
→ Quick add writes a bare task line to Inbox.md (configurable path)
→ Checkoff calls executeToggleTaskDoneCommand()
→ Click task text → calls Tasks API modal
→ Progress bar + stats calculated from today's task count
Week View
→ Full window view registered as a separate Leaf
→ 7 columns, tasks grouped by scheduled/due date
→ Drag and drop rewrites the date field in the source .md file directly
→ Click card → Tasks plugin modal for full edit
→ Filter chips toggle scheduled vs due date display
→ Works on mobile — columns scroll horizontally
Tasks Plugin Integration
→ apiV1.createOrEdit(task, file) — edit modal
→ Reads all tasks by scanning vault .md files for task syntax
→ Respects all statuses, recurrence, and emoji date fields
→ Settings: inbox path, group by (note/heading), default date field (scheduled vs due)
